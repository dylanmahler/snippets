# Snippets

Each folder is one design-engineering study. Change only the snippet you were asked to change.

Before building or revising a snippet, read `.cursor/skills/snippet-craft/SKILL.md` and apply the checklist. Still the opening and the payoff before tuning motion. Films follow `.cursor/skills/snippet-craft/video-playbook.md`.

Reference skills, read them, do not paste them into a snippet:

- Benji Taylor, Stageshow: https://github.com/benjitaylor/skills/tree/main/stageshow including `references/craft.md`, `references/motion.md`, and `references/rehearse.md`
- Emil Kowalski: https://github.com/emilkowalski/skills (`emil-design-eng`, `choreograph`, `gestures`)
